# assignments

课程作业归档目录。每份作业建立一个独立文件夹，命名建议：

```
hw<序号>-<主题>/
```

示例：
- `hw01-data-analysis/`  — 数据清洗与探索性分析
- `hw02-ml-model/`       — 机器学习建模
- `hw03-llm-app/`        — 大模型应用

## 作业提交清单（自检表）

提交每份作业前，请确认：

- [ ] 代码放在对应作业文件夹内
- [ ] 代码可运行，必要依赖已在文件夹内注明
- [ ] 运行结果 / 截图 / 说明已整理
- [ ] 提交信息清晰（说明本次完成内容）
- [ ] 大数据文件未直接提交，已在说明中注明来源
